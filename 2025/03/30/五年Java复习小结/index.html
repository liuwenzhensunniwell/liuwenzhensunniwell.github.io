五年Java复习小结

发表于2025-03-30|更新于2025-03-30
|阅读量:

1. Java核心基础

常见问题：

1.HashMap的底层实现原理是什么？1.7和1.8有什么区别？

答：HashMap基于哈希表，1.7用数组+链表，1.8引入红黑树优化（当链表长度>8时转为树）。1.8还改进了hash算法和扩容机制。

2.synchronized和ReentrantLock的区别？

答：synchronized是关键字，JVM实现，简单但不够灵活；ReentrantLock是显式锁，支持公平锁、条件变量、更灵活但需要手动释放。

3.volatile关键字的作用和原理？

答：保证可见性和禁止指令重排，底层通过内存屏障实现，不保证原子性。

4.Java内存模型（JMM）是什么？

答：定义线程和工作内存、主内存的交互规则，核心是 happens-before 关系。

5.ThreadLocal的原理和使用场景？内存泄漏怎么解决？

答：ThreadLocal为每个线程提供独立变量副本，底层用ThreadLocalMap。内存泄漏需在finally中调用remove()。

2. 集合框架

常见问题：

1.ArrayList和LinkedList的区别？

答：ArrayList基于动态数组，随机访问快；LinkedList基于双向链表，插入删除快。

2.ConcurrentHashMap如何实现线程安全？

答：1.7用分段锁（Segment），1.8用CAS+synchronized+红黑树，减少锁粒度。

3.CopyOnWriteArrayList适用于什么场景？

答：读多写少场景，写时复制新数组，读无锁。

3. 多线程与并发

常见问题：

1.线程池的核心参数有哪些？如何配置？

答：corePoolSize、maximumPoolSize、keepAliveTime、workQueue等。配置根据任务类型（CPU密集：核心数+1；IO密集：核心数*2）。

2.CAS是什么？ABA问题怎么解决？

答：Compare-And-Swap，无锁优化。ABA用版本号（AtomicStampedReference）。

3.ExecutorService和CompletableFuture的区别？

答：ExecutorService是线程池管理工具，CompletableFuture是异步编程工具，支持链式调用。

4.死锁的条件是什么？如何排查？

答：互斥、持有并等待、不可抢占、循环等待。用jstack或ThreadMXBean排查。

4. Spring框架

常见问题：

1.Spring IOC和AOP的原理是什么？

答：IOC通过反射和工厂模式实现依赖注入；AOP基于动态代理（JDK代理或CGLIB）。

2.Bean的生命周期有哪些步骤？

答：实例化 -> 属性填充 -> 初始化（Aware接口、@PostConstruct） -> 使用 -> 销毁。

3.@Transactional的失效场景有哪些？

答：非public方法、类内自调用、异常被捕获未抛出、数据库不支持事务。

4.Spring Boot自动配置的原理？

答：基于@Conditional条件注解和META-INF/spring.factories加载配置。

5. 微服务与分布式

常见问题：

1.分布式事务的解决办法有哪些？

答：2PC、TCC、Saga、消息队列+最终一致性。

2.Spring Cloud的核心组件有哪些？

答：Eureka（服务注册）、Ribbon/Feign（负载均衡）、Zuul/Gateway（网关）、Hystrix（熔断）。

3.CAP理论是什么？如何选择？

答：一致性（C）、可用性（A）、分区容忍性（P），分布式系统只能选其二。互联网多选AP。

4.如何实现服务限流？

答：令牌桶（RateLimiter）、漏桶、计数器，结合Sentinel或Hystrix。

6. 数据库与中间件

常见问题：

1.MySQL索引的原理是什么？B+树的优势？

答：B+树叶子节点存数据，非叶子节点存索引，范围查询效率高。

2.事务的ACID特性如何实现？

答：原子性（undo log）、一致性（约束）、隔离性（锁/MVCC）、持久性（redo log）。

3.Redis的线程模型和持久化机制？

答：单线程+IO多路复用，持久化有RDB（快照）和AOF（日志）。

4.Kafka如何保证消息不丢失？

答：生产者ACKS=-1，消费者手动提交offset，副本机制。

7. 算法与设计模式

常见问题：

1.手写LRU缓存（Least Recently Used）

答：用HashMap + 双向链表实现。

2.单例模式的几种实现方式？

答：饿汉、懒汉、双重检查锁、静态内部类、枚举。

3.观察者模式在Spring中的应用？

答：ApplicationListener监听事件。

8. 系统设计

常见问题：

1.设计一个秒杀系统？

答：前端限流（按钮置灰）、后端限流（Redis令牌桶）、库存预减（Redis扣减）、异步下单（MQ）。

2.如何设计一个短网址服务？

答：用62进制编码生成短码，数据库存映射，Redis缓存热点URL。

3.高并发场景下如何优化？

答：负载均衡（Nginx）、缓存（Redis）、异步（MQ）、数据库分库分表。

2.如何对接微信/支付宝支付？

答：用官方SDK，Java调用API，处理回调。

3.项目中如何保证代码质量？

答：单元测试（JUnit）、代码审查、SonarQube扫描。
