Spring AOP的两种代理区别，写一个简单的自定义切面示例

Spring AOP 的两种代理方式区别：

1. JDK 动态代理

  • 基于接口实现
  • 要求目标类必须实现接口
  • 通过 Java 的 Proxy 类生成代理对象
  • 性能稍高

2. CGLIB 代理

  • 基于类继承
  • 不要求目标类实现接口
  • 通过字节码生成子类实现代理
  • 对 final 类或方法无效

关键点说明：

  1. @Aspect 标注这是一个切面类
  2. @Pointcut 定义切入点表达式，这里匹配 service 包下所有类的所有方法
  3. 使用不同类型的通知（@Before, @After 等）实现横切关注点
  4. @EnableAspectJAutoProxy 启用 AOP，proxyTargetClass 参数决定使用哪种代理方式
  5. JoinPoint 参数可获取方法签名、参数等信息

这个示例展示了一个简单的日志切面，你可以根据需要修改切点表达式和通知逻辑来实现其他功能，比如性能监控、事务管理等。
